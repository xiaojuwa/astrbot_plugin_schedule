# 课表查询与提醒插件

这是一个我为了方便提醒对象上课用AI开发的插件（就连这个README都是AI写的），这个插件可以用于查询课表信息并提供课前提醒功能的插件。可以通过简单的命令查询当天或指定日期的课表，可以设置通过命令课程开始前1小时收到提醒。

## 功能

- **课表查询**：支持查询今天、明天或指定周几的课表。
- **课前提醒**：在每节课开始前1小时发送提醒通知。
- **通知管理**：用户可以开启或关闭课程提醒功能，并查看当前通知状态。

## 使用方法

- 输入 `/课表` 查看今天的课表。
- 输入 `/课表 今天` 查看今天的课表。
- 输入 `/课表 明天` 查看明天的课表。
- 输入 `/课表 周一` 查看下周一的课表（同理可查看周二到周日）。
- 输入 `/开启课程提醒` 开启课前1小时提醒功能。
- 输入 `/关闭课程提醒` 关闭课前提醒功能。


- `notification_config.json`：用于配置通知功能的启用状态和通知目标，发送 '/开启课程提醒' 自动生成
- `reminder_cache.json`：用于存储已发送的课程提醒记录，避免重复发送提醒。
- `kebiao.json`：用于存储课表数据
